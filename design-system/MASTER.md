# Ahmed Bashamekh / Portfolio studio direction

## Brief and design review
Audience: hiring managers, software teams, and potential collaborators.
Purpose: make Ahmed's real projects and practical engineering range memorable and easy to explore.
The previous bright panels and coin illustration read as playful decoration. This revision uses a quiet gallery canvas, readable type, actual project-site captures, and a single sculptural interaction.

## Tokens
- Paper #F5F5F2: main gallery canvas.
- Ink #191D28: primary text.
- Blue #3159E8: actions and the 3D sculpture.
- Mist #E8ECF3: media surfaces.
- Night #161C2C: career section.
- Silver #BFCADD: accents and material reflection.

## Typography
Archivo for display: clean, large, slightly condensed headings.
Manrope for reading and navigation: body 16px minimum, 1.7 line height.
No decorative numbering, tiny labels, or tracked all-caps.

## Motion and interaction
Jakub production polish primary; Jhey creative expression secondary.
One orchestrated hero entrance. Action-driven card perspective, project filters, native dialogs, experience accordions, and clipboard feedback.
Sculpture uses real lighting and reflective materials, horizontal touch drag, arrow-key controls, surface/wireframe views, reset, and pause.
A Sculpture/Laptop selector retains the original default and offers a modeled aluminum laptop with a custom illustrated IDE. Its ambient motion is a subtle float so the code stays readable.
The selector also includes the avatar created in the companion task, following Ahmed's explicit decision to retain all three versions.
The engineering strip uses monochrome technology marks in a slow continuous loop, with explicit pause, hover/focus pause, and offscreen suspension. Reduced motion shows a static horizontally scrollable strip.
No scroll hijacking. Ambient rendering stops offscreen and in inactive tabs.

## Truth and quality
Hassel and Qabas images are captures of their actual public live sites, including the sites' own illustrative content.
Invaro information comes from the supplied CV. Sanad has no invented stack, metrics, or features.
Use actual PDF resume and live URLs; repository links require the user's real GitHub URLs.
Readability, 44px controls, semantic markup, native dialog focus, reduced motion, mobile and landscape review, production build.
